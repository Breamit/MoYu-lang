## grammar

### how to declare a variable
When we wanna declare a variable , we can use the `let` keyword.

```my
let a : i32 = 10;
```

Of course , we can also declare a constant variable with the `const` keyword.

```my
const a : i32 = 10;
```

You may have noticed that all variable declarations have type annotations. That's correct. In version `0.1-beta`, we required that when declaring variables, type annotations must be provided.

### what kind of type are supported

we offer many kind of type of basic object. Here are some of them:

- `i32`: 32-bit signed integer
- `i64`: 64-bit signed integer
- `u32`: 32-bit unsigned integer
- `u64`: 64-bit unsigned integer
- `bool`: boolean value
- `f64`: 64-bit floating-point number
- `f32`: 32-bit floating-point number
- `string`: string encode in utf-8
- `null`: null value
- `none`: none value , it's void type , not same as null 
- `list`: list of objects
- `map`: map of key-value pairs

Except for `string`、`none`、`list`、`map`, all the remaining types support basic operator operations.

### basic operator operations

We offer basic operator operations for all the remaining types.

- `=`: assignment operator
- `+`:  plus operator
- `-`:  minus operator
- `*`   multiply operator
- `/`   divide operator
- `%`   modulus operator
- `^`   xor operator
- `&`   bitwise and operator
- `|`   bitwise or operator
- `!`   not operator
- `<`   less than operator
- `>`   greater than operator
- `<=`  less than or equal to operator
- `>=`  greater than or equal to operator
- `==`  equal operator
- `!=`  not equal operator



### loop

We offer two kind of loop:
- `for` loop
- `while` loop

Fortunately, the grammars of these two types of loop statements are almost exactly the same as those of mainstream languages.

#### for-statement
```my
for(let i : i32 = 0; i<10;i = i + 1) {
    println(i);
}
```

#### while-statement
```my
let flag:bool = true;

while(flag) {
    let i : i32 = sys.random(1,100);
    if(i >= 50) {
        flag = false;
        println(i);
    }
}
```

Of course , we can also control the loop with the `break` keyword and the `continue` keyword.

#### break-statement and continue-statement

The usage of `break` and `continue` is similar to that in mainstream programming languages, and they are used to handle loops and `switch` branches.

### choice

we offer two kind of choice:
- `if` branch statement
- `switch` branch statement

Since we follow the C-like syntax, this aspect is almost the same as in C language or mainstream programming languages. The only difference is the mandatory statement block syntax of the `switch` keyword.

#### if-statement

If statement contains three keywords:
- `if`
- `else`
- `elif`

it's like python's if-statement.

```my
if (condition) {
    // do something
} elif (condition2) {
    // do something else
} elif (condition3) {
    // do something else
} else {
    // do something else
}
```

In MoYu language , the `elif` and `else` is not required. If you don't use them , the program will not be affected.

#### switch-statement

Switch statement contains four keywords:
- `switch`
- `case`
- `default`
- `break`

Among them, `break` can also be used as a keyword in loop statements.


```my
switch(condition) {
    case value1:{
        // do something
        break;
        }
    case value2:{
        // do something else
        break;
        }
    default:{
        // do something else
        break;
        }
}
```

You may found that the `case` branch must follow block statement. 

What is the usage of `break`? 
If there is no `break`, then there will be a situation where the "switch" statement overflows.
In next version , we will fix this *required block-statements* problem.

### function

In MoYu language, functions are declared using the `fn` keyword. Functions can have parameters with type annotations and a return type.

```my
fn add(a: i32, b: i32): i32 {
    return a + b;
}
```

The return type is specified after the parameter list with a colon. If the function does not return a value, use `void` as the return type:

```my
fn greet(name: string): void {
    println("Hello, " + name);
}
```

Functions can also be marked as asynchronous using the `@async` annotation, and can be awaited using the `await` keyword:

```my
@async
@native('vm.http.fetch')
fn fetch(url: string): string;

fn main(): void {
    let result = await fetch('http://example.com');
    println(result);
}
```

### struct

Structs are declared using the `struct` keyword. Structs can have fields with type annotations:

```my
struct Point {
    x: i32,
    y: i32
};
```

You can create instances of structs using the constructor with a map literal:

```my
let p = Point({'x': 10, 'y': 20});
```

To define methods on structs, use the `@method` annotation:

```my
@method(Point)
fn out(self: Point): void {
    println(self.x, self.y);
}
```

To mark a struct for object construction, use the `@object` annotation:

```my
@object
struct Person {
    name: string,
    age: u32
};

let person = Person({});
person.name = 'Alice';
person.age = 18;
```

### enum

Enums are declared using the `enum` keyword:

```my
enum Color {
    red,
    blue,
    green,
};
```

### annotation

MoYu supports several annotations that modify the behavior of functions and structs:

- `@native(name)`: Marks a function as a native function that calls external code
- `@platform(platforms...)`: Specifies which platforms the function/struct supports
- `@method(name)`: Marks a function as a method that can be called with the dot operator
- `@object`: Marks a struct as a construction-enabled object
- `@async`: Marks a function as asynchronous

```my
@native('math.sqrt')
fn sqrt(x: f64): f64;

@async
@native('vm.http.fetch')
fn fetch(url: string): string;

@object
struct Config {
    path: string,
};
```

### package

You can import other modules using the `import` keyword:

```my
import io;
import std;
```

You can export functions or variables using the `export` keyword:

```my
export myFunction;
export {
    func1,
    func2
};
```

### boolean operators

MoYu supports boolean operators:

- `not`: logical NOT
- `or`: logical OR
- `and`: logical AND

```my
let a = true;
let b = false;
let c = not a;
let d = a or b;
let e = a and b;
```

### bit operators

In addition to the basic operators, MoYu also supports bit-level operations:

- `~`: bitwise NOT
- `&`: bitwise AND
- `|`: bitwise OR
- `^`: bitwise XOR

```my
let z = ~0;        // bitwise NOT
let x = 1 & 2;    // equals 0
let y = 1 | 2;    // equals 3
let z = 1 ^ 2;    // equals 3
```

### index access

You can access elements in list or map using the index operator `[]`:

```my
let arr: list = [1, 2, 3];
let first = arr[0];

let mp: map = {'key': 'value'};
let val = mp['key'];
mp['newkey'] = 'newvalue';
```

### type conversion

MoYu supports automatic type conversion for basic types. When assigning values or passing parameters, type conversion happens automatically:

```my
let x: i32 = 10;
let y: f64 = x;    // i32 to f64 automatically

let a: f64 = 5.5;
let b: i32 = a;    // f64 to i32 automatically
```

Note: Automatic type conversion only works for basic types, not for custom types.

### special types

- `any`: Can represent any type. Note: `any` type can only be used in function type annotations, not in variable declarations.

```my
fn printValue(value: any): void {
    io.println(value);
}
```
