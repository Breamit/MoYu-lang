d# MoYu 语言语法

## 版本
**- 版本：v0.1-beta**
**- 版本号：0.1**

## 特性

1. 支持多种基础对象类型
2. 语法简洁，符合常见习惯
3. 内置 io / file / json / math / os / time 等模块
4. 编译期类型检查器，可在运行前捕获类型错误

## 注释

在 MoYu 语言中，我们使用 `#` 作为单行注释。注释从 `#` 开始，一直到行尾结束。

```my
# 这是一条注释
let a : i32 = 10;   # 行尾注释
```

## 语法

### 如何声明变量

当我们想要声明一个变量时，可以使用 `let` 关键字。

```my
let a : i32 = 10;
```

当然，我们也可以使用 `const` 关键字来声明常量。

```my
const a : i32 = 10;
```

类型标注是**可选的**。如果你不提供类型标注，类型检查器会尝试根据值来推断类型。

```my
let a = 10;          # 推断为 i64
let b = "hello";     # 推断为 string
let c : i32 = 10;    # 显式标注
```

我们仍然建议提供类型标注，因为它可以让代码更清晰，也能让类型检查器更好地验证你的代码。

### 支持哪些类型

我们提供了多种基础对象类型。以下是其中一些：

- `i32`：32 位有符号整数
- `u32`：32 位无符号整数
- `i64`：64 位有符号整数
- `u64`：64 位无符号整数
- `f32`：32 位浮点数
- `f64`：64 位浮点数
- `bool`：布尔值，`true` 或 `false`
- `string`：以 UTF-8 编码的字符串
- `bytes`：字节序列，等同于 `u8[]`
- `u8`：8 位无符号整数，即一个字节
- `null`：空值
- `none`：无值，即 void 类型，与 null 不同
- `list`：对象列表
- `map`：键值对映射
- `any`：可以表示任意类型，一种动态类型
- `lambda`：函数值，通常由函数字面量创建

除了 `string`、`none`、`list`、`map`、`bytes`、`lambda` 之外，其余所有类型都支持基础运算符操作。

### 基础运算符操作

我们为数值类型和布尔类型提供了基础运算符操作。

- `=`：赋值运算符
- `+`：加法运算符
- `-`：减法运算符
- `*`：乘法运算符
- `/`：除法运算符
- `%`：取模运算符
- `<`：小于运算符
- `>`：大于运算符
- `<=`：小于等于运算符
- `>=`：大于等于运算符
- `==`：等于运算符
- `!=`：不等于运算符

### 布尔运算符

MoYu 支持布尔运算符：

- `not`：逻辑非
- `and`：逻辑与
- `or`：逻辑或

```my
let a = true;
let b = false;
let c = not a;      # false
let d = a or b;     # true
let e = a and b;    # false
```

### 位运算符

除了基础运算符之外，MoYu 还支持对整数进行位级操作：

- `~`：按位取反
- `&`：按位与
- `|`：按位或
- `^`：按位异或

```my
let x = 1 & 2;    # 等于 0
let y = 1 | 2;    # 等于 3
let z = 1 ^ 2;    # 等于 3
```

### 循环

我们提供两种循环：
- `for` 循环
- `while` 循环

幸运的是，这两种循环语句的语法几乎和主流语言完全一致。

#### for 语句

```my
for(let i : i32 = 0; i < 10; i = i + 1) {
    io.println(i);
}
```

`for` 循环包含三个部分：初始化语句、条件和更新表达式。

#### while 语句

```my
let flag : bool = true;

while(flag) {
    let i : i32 = os.getPid();
    if(i >= 50) {
        flag = false;
        io.println(i);
    }
}
```

我们也可以使用 `break` 关键字和 `continue` 关键字来控制循环。

#### break 语句和 continue 语句

`break` 和 `continue` 的用法与主流编程语言类似，用于处理循环和 `switch` 分支。

```my
for(let i : i32 = 0; i < 10; i = i + 1) {
    if(i == 3) {
        continue;   # 跳过剩余部分，进入下一次迭代
    }
    if(i == 8) {
        break;      # 退出循环
    }
    io.println(i);
}
```

### 分支选择

我们提供两种分支选择：
- `if` 分支语句
- `switch` 分支语句

由于我们遵循类 C 语法，这方面几乎和 C 语言或主流编程语言一样。唯一的区别是 `switch` 关键字强制使用语句块语法。

#### if 语句

If 语句包含三个关键字：
- `if`
- `elif`
- `else`

它类似于 Python 的 if 语句。

```my
if (condition) {
    # 做某事
} elif (condition2) {
    # 做另一件事
} elif (condition3) {
    # 做另一件事
} else {
    # 做另一件事
}
```

在 MoYu 语言中，`elif` 和 `else` 不是必须的。如果你不使用它们，程序不会受到影响。

#### switch 语句

Switch 语句包含四个关键字：
- `switch`
- `case`
- `default`
- `break`

其中，`break` 也可以作为循环语句中的关键字。

```my
switch(condition) {
    case 1:{
        # 做某事
        break;
    }
    case 2:{
        # 做另一件事
        break;
    }
    default:{
        # 做另一件事
        break;
    }
}
```

你可能会发现，`case` 分支后面必须跟一个块语句。这是有意设计的。

### 函数

在 MoYu 语言中，使用 `fn` 关键字声明函数。函数可以带有类型标注的参数和返回类型。

```my
fn add(a : i32, b : i32) : i32 {
    return a + b;
}
```

返回类型在参数列表之后用冒号指定。如果函数不返回值，使用 `void` 作为返回类型：

```my
fn greet(name : string) : void {
    io.println("Hello, " + name);
}
```

函数可以没有函数体，当它们通过 `@native` 注解绑定到原生实现时：

```my
@native('math.sqrt')
fn sqrt(x : f64) : f64;
```

函数可以使用 `@async` 注解标记为异步函数，并可以使用 `await` 关键字进行等待：

```my
@async
@native('vm.http.fetch')
fn fetch(url : string) : string;

fn main() : void {
    let result = await fetch('http://example.com');
    io.println(result);
}
```

> **注意**：`await` / 协程在 **v1.0 尚未实现**。语法已被解析，但 `await` 目前只是同步求值其内部表达式（不会挂起）。完整的协程支持计划在未来的版本中实现。

#### lambda（匿名函数）

#### lambda（匿名函数）

函数也可以作为值来创建，使用函数字面量。这被称为 lambda。它可以存储在变量中或作为参数传递。

```my
let square = fn(x : i32) : i32 {
    return x * x;
};

io.println(square(4));    # 16
```

### 结构体

结构体使用 `struct` 关键字声明。结构体可以带有类型标注的字段。

```my
struct Point {
    x : i32,
    y : i32
};
```

你可以使用带有 map 字面量的构造函数来创建结构体实例：

```my
let p = Point({'x': 10, 'y': 20});
```

你可以使用点运算符访问字段：

```my
let px = p.x;    # 10
```

要在结构体上定义方法，使用 `@method` 注解。方法的第一个参数必须是 `self`，它代表实例本身：

```my
@method(Point)
fn out(self : Point) : void {
    io.println(self.x, self.y);
}

let p = Point({'x': 10, 'y': 20});
p.out();    # 调用方法
```

结构体字段也可以存储 lambda，方法可以通过 `self` 调用它：

```my
struct Demo {
    func : lambda,
    p : i32
};

@method(Demo)
fn testDemo(self : Demo) : void {
    self.func(self.p);
}

let obj = Demo({'func': fn(x : i32) : void { io.println(x * x); }, 'p': 4});
obj.testDemo();    # 16
```

### 注解

MoYu 支持多种注解，用于修改函数和结构体的行为：

- `@native(name)`：将函数标记为调用外部代码的原生函数
- `@platform(platforms...)`：指定函数/结构体支持哪些平台
- `@method(name)`：将函数标记为可以用点运算符调用的方法
- `@async`：将函数标记为异步函数

```my
@native('math.sqrt')
fn sqrt(x : f64) : f64;

@async
@native('vm.http.fetch')
fn fetch(url : string) : string;

@method(Point)
fn distance(self : Point) : f64 {
    return math.sqrt(self.x * self.x + self.y * self.y);
}
```

### 包

你可以使用 `import` 关键字导入其他模块：

```my
import io;
import fs;
import math;
```

你可以使用 `export` 关键字导出函数或变量：

```my
export {
    func1,
    func2
};
```

你也可以导出单个条目：

```my
export func1;
```

### 索引访问

你可以使用索引运算符 `[]` 访问列表或 map 中的元素：

```my
let arr : list = [1, 2, 3];
let first = arr[0];          # 1

let mp : map = {'key': 'value'};
let val = mp['key'];         # 'value'
mp['newkey'] = 'newvalue';
```

### 类型转换

MoYu 支持基础数值类型之间的自动类型转换。在赋值或传参时，类型转换会自动发生：

```my
let x : i32 = 10;
let y : f64 = x;    # i32 自动转换为 f64

let a : f64 = 5.5;
let b : i32 = a;    # f64 自动转换为 i32
```

注意：自动类型转换仅适用于基础类型，不适用于自定义类型。

### 特殊类型

- `any`：可以表示任意类型。它既可以用于变量声明，也可以用于函数标注。

```my
let anything : any = 123;          # any 持有一个整数
anything = "now it's a string";    # any 持有一个字符串

fn printValue(value : any) : void {
    io.println(value);
}
```

- `lambda`：函数值的类型。

```my
let f : lambda = fn(x : i32) : i32 { return x * 2; };
```

### 类型检查器

MoYu 有一个编译期类型检查器。在程序运行之前，它会遍历 AST，推断类型并验证类型标注是否一致。

例如，这段代码是错误的，类型检查器会报错：

```my
let x : i32 = "hello";    # 不能将 string 赋值给 i32
```

错误信息会打印到标准错误输出，但程序仍然会运行。类型检查器是一个编译期辅助工具，它不会改变程序的行为。

### 内置模块

MoYu 提供了多个内置模块。使用前需要先导入。

- `io`：输入 / 输出，如 `io.println`、`io.print`、`io.getInt`
- `fs`：文件系统，如 `fs.readText`、`fs.writeText`、`fs.exists`、`fs.listDir`
- `json`：JSON 解析与序列化，如 `json.parse`、`json.stringify`
- `math`：数学函数，如 `math.sqrt`、`math.sin`、`math.abs`
- `os`：操作系统，如 `os.pwd`、`os.getEnv`、`os.exec`
- `time`：时间函数，如 `time.now`、`time.nowf`

```my
import io;
import fs;

let content : string = fs.readText('./config.txt');
io.println(content);
```
