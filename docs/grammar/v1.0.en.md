# MoYu Language Grammar

## version
**- version : v0.1-beta**
**- version number : 0.1**

## feature

1. support many kind of basic object type
2. the grammar is simple and common-seen
3. built-in modules for io / file / json / math / os / time
4. a compile-time type checker that helps to catch type errors before running

## comment

In MoYu language, we use `#` for single-line comments. The comment runs from `#` to the end of the line.

```my
# this is a comment
let a : i32 = 10;   # comment at the end of a line
```

## grammar

### how to declare a variable

When we wanna declare a variable, we can use the `let` keyword.

```my
let a : i32 = 10;
```

Of course, we can also declare a constant variable with the `const` keyword.

```my
const a : i32 = 10;
```

The type annotation is **optional**. If you don't provide it, the type checker will try to infer the type from the value.

```my
let a = 10;          # inferred as i64
let b = "hello";     # inferred as string
let c : i32 = 10;    # explicit annotation
```

We still recommend providing the type annotation, because it makes the code clearer and lets the type checker verify your code.

### what kind of type are supported

We offer many kind of type of basic object. Here are some of them:

- `i32`: 32-bit signed integer
- `u32`: 32-bit unsigned integer
- `i64`: 64-bit signed integer
- `u64`: 64-bit unsigned integer
- `f32`: 32-bit floating-point number
- `f64`: 64-bit floating-point number
- `bool`: boolean value, `true` or `false`
- `string`: string encode in utf-8
- `bytes`: a sequence of bytes, equal to `u8[]`
- `u8`: 8-bit unsigned integer, a byte
- `null`: null value
- `none`: none value, it's the void type, not same as null
- `list`: list of objects
- `map`: map of key-value pairs
- `any`: can represent any type, a dynamic type
- `lambda`: a function value, usually created by a function literal

Except for `string`、`none`、`list`、`map`、`bytes`、`lambda`, all the remaining types support basic operator operations.

### basic operator operations

We offer basic operator operations for the numeric and boolean types.

- `=`: assignment operator
- `+`: plus operator
- `-`: minus operator
- `*`: multiply operator
- `/`: divide operator
- `%`: modulus operator
- `<`: less than operator
- `>`: greater than operator
- `<=`: less than or equal to operator
- `>=`: greater than or equal to operator
- `==`: equal operator
- `!=`: not equal operator

### boolean operators

MoYu supports boolean operators:

- `not`: logical NOT
- `and`: logical AND
- `or`: logical OR

```my
let a = true;
let b = false;
let c = not a;      # false
let d = a or b;     # true
let e = a and b;    # false
```

### bit operators

In addition to the basic operators, MoYu also supports bit-level operations on integers:

- `~`: bitwise NOT
- `&`: bitwise AND
- `|`: bitwise OR
- `^`: bitwise XOR

```my
let x = 1 & 2;    # equals 0
let y = 1 | 2;    # equals 3
let z = 1 ^ 2;    # equals 3
```

### loop

We offer two kind of loop:
- `for` loop
- `while` loop

Fortunately, the grammars of these two types of loop statements are almost exactly the same as those of mainstream languages.

#### for-statement

```my
for(let i : i32 = 0; i < 10; i = i + 1) {
    io.println(i);
}
```

The `for` loop has three parts: the init statement, the condition and the update expression.

#### while-statement

```my
let flag : bool = true;

while(flag) {
    let i : i32 = os.getPid();
    if(i >= 50) {
        flag = false;
        io.println(i);
    }
}
```

We can also control the loop with the `break` keyword and the `continue` keyword.

#### break-statement and continue-statement

The usage of `break` and `continue` is similar to that in mainstream programming languages, and they are used to handle loops and `switch` branches.

```my
for(let i : i32 = 0; i < 10; i = i + 1) {
    if(i == 3) {
        continue;   # skip the rest and go to next iteration
    }
    if(i == 8) {
        break;      # exit the loop
    }
    io.println(i);
}
```

### choice

We offer two kind of choice:
- `if` branch statement
- `switch` branch statement

Since we follow the C-like syntax, this aspect is almost the same as in C language or mainstream programming languages. The only difference is the mandatory statement block syntax of the `switch` keyword.

#### if-statement

If statement contains three keywords:
- `if`
- `elif`
- `else`

It's like python's if-statement.

```my
if (condition) {
    # do something
} elif (condition2) {
    # do something else
} elif (condition3) {
    # do something else
} else {
    # do something else
}
```

In MoYu language, the `elif` and `else` are not required. If you don't use them, the program will not be affected.

#### switch-statement

Switch statement contains four keywords:
- `switch`
- `case`
- `default`
- `break`

Among them, `break` can also be used as a keyword in loop statements.

```my
switch(condition) {
    case 1:{
        # do something
        break;
    }
    case 2:{
        # do something else
        break;
    }
    default:{
        # do something else
        break;
    }
}
```

You may find that the `case` branch must follow a block statement. This is by design.

### function

In MoYu language, functions are declared using the `fn` keyword. Functions can have parameters with type annotations and a return type.

```my
fn add(a : i32, b : i32) : i32 {
    return a + b;
}
```

The return type is specified after the parameter list with a colon. If the function does not return a value, use `void` as the return type:

```my
fn greet(name : string) : void {
    io.println("Hello, " + name);
}
```

Functions can be declared without a body, when they are bound to a native implementation through the `@native` annotation:

```my
@native('math.sqrt')
fn sqrt(x : f64) : f64;
```

Functions can be marked as asynchronous using the `@async` annotation, and can be awaited using the `await` keyword:

```my
@async
@native('vm.http.fetch')
fn fetch(url : string) : string;

fn main() : void {
    let result = await fetch('http://example.com');
    io.println(result);
}
```

#### lambda

A function can also be created as a value, using a function literal. This is called a lambda. It can be stored in a variable or passed as an argument.

```my
let square = fn(x : i32) : i32 {
    return x * x;
};

io.println(square(4));    # 16
```

### struct

Structs are declared using the `struct` keyword. Structs can have fields with type annotations.

```my
struct Point {
    x : i32,
    y : i32
};
```

You can create instances of structs using the constructor with a map literal:

```my
let p = Point({'x': 10, 'y': 20});
```

You can access the fields with the dot operator:

```my
let px = p.x;    # 10
```

To define methods on structs, use the `@method` annotation. The first parameter of a method must be `self`, which represents the instance itself:

```my
@method(Point)
fn out(self : Point) : void {
    io.println(self.x, self.y);
}

let p = Point({'x': 10, 'y': 20});
p.out();    # call the method
```

A struct field can also store a lambda, and methods can call it through `self`:

```my
struct Demo {
    func : lambda,
    p : i32
};

@method(Demo)
fn testDemo(self : Demo) : void {
    self.func(self.p);
}

let obj = Demo({'func': fn(x : i32) : void { io.println(x * x); }, 'p': 4});
obj.testDemo();    # 16
```

### annotation

MoYu supports several annotations that modify the behavior of functions and structs:

- `@native(name)`: Marks a function as a native function that calls external code
- `@platform(platforms...)`: Specifies which platforms the function/struct supports
- `@method(name)`: Marks a function as a method that can be called with the dot operator
- `@async`: Marks a function as asynchronous

```my
@native('math.sqrt')
fn sqrt(x : f64) : f64;

@async
@native('vm.http.fetch')
fn fetch(url : string) : string;

@method(Point)
fn distance(self : Point) : f64 {
    return math.sqrt(self.x * self.x + self.y * self.y);
}
```

#### platform filtering

The `@platform` annotation declares which operating systems a function or struct targets. At compile time, if the current OS is **not** in the list, the whole annotated node is removed before type checking and running.

```my
@platform(Windows, Linux)
fn init() : void {
    # runs on Windows and Linux only
}

@platform(MacOS)
fn macOnly() : void {
    # removed on non-Mac platforms
}
```

Supported platform names: `Windows`, `Linux`, `MacOS`. Matching is case-insensitive.

### container methods

The built-in types `list`, `string` and `map` provide member methods callable with the dot operator.

**list**

| method | description |
|---|---|
| `size()` | number of elements |
| `get(i)` | element at index `i` (error if out of range) |
| `set(i, v)` | set element at index `i` (error if out of range) |
| `push(x)` / `append(x)` | append element at the end |
| `pop()` | remove and return the last element |

```my
let l : list = [1, 2, 3];
io.println(l.size());      # 3
l.push(4);
io.println(l.pop());       # 4
```

**string**

| method | description |
|---|---|
| `size()` | byte length |
| `substring(a, b)` | substring from `a` (inclusive) to `b` (exclusive) |
| `contains(x)` | whether it contains substring `x` |
| `count(x)` | how many times substring `x` appears |

```my
let s : string = "hello";
io.println(s.size());              # 5
io.println(s.substring(1, 3));     # "el"
io.println(s.contains("ell"));     # true
io.println(s.count("l"));          # 2
```

**map**

| method | description |
|---|---|
| `size()` | number of key-value pairs |
| `get(k)` | value for key `k` (error if key missing) |
| `set(k, v)` | set key-value pair |
| `contains(k)` / `has(k)` | whether the key exists |
| `keys()` | list of all keys |
| `values()` | list of all values |

```my
let m : map = {"a": 1, "b": 2};
io.println(m.size());          # 2
m.set("c", 3);
io.println(m.contains("c"));   # true
io.println(m.keys());          # [a, b, c]
```

### package

You can import other modules using the `import` keyword:

```my
import io;
import fs;
import math;
```

You can export functions or variables using the `export` keyword:

```my
export {
    func1,
    func2
};
```

You can also export a single item:

```my
export func1;
```

### index access

You can access elements in a list or map using the index operator `[]`:

```my
let arr : list = [1, 2, 3];
let first = arr[0];          # 1

let mp : map = {'key': 'value'};
let val = mp['key'];         # 'value'
mp['newkey'] = 'newvalue';
```

### type conversion

MoYu supports automatic type conversion for basic numeric types. When assigning values or passing parameters, type conversion happens automatically:

```my
let x : i32 = 10;
let y : f64 = x;    # i32 to f64 automatically

let a : f64 = 5.5;
let b : i32 = a;    # f64 to i32 automatically
```

Note: Automatic type conversion only works for basic types, not for custom types.

### special types

- `any`: can represent any type. It can be used both in variable declarations and function annotations.

```my
let anything : any = 123;          # any holds an integer
anything = "now it's a string";    # any holds a string

fn printValue(value : any) : void {
    io.println(value);
}
```

- `lambda`: the type of a function value.

```my
let f : lambda = fn(x : i32) : i32 { return x * 2; };
```

### type checker

MoYu has a compile-time type checker. Before the program runs, it walks through the AST, infers types and verifies that type annotations are consistent.

For example, this code is wrong and the type checker will report an error:

```my
let x : i32 = "hello";    # cannot assign string to i32
```

The error message is printed to the standard error, but the program still runs. The type checker is a compile-time aid, it does not change the behavior of the program.

### built-in modules

MoYu provides several built-in modules. You need to import them before use.

- `io`: input / output, such as `io.println`, `io.print`, `io.getInt`
- `fs`: file system, such as `fs.readText`, `fs.writeText`, `fs.exists`, `fs.listDir`
- `json`: json parse and stringify, such as `json.parse`, `json.stringify`
- `math`: math functions, such as `math.sqrt`, `math.sin`, `math.abs`
- `os`: operating system, such as `os.pwd`, `os.getEnv`, `os.exec`
- `time`: time functions, such as `time.now`, `time.nowf`

```my
import io;
import fs;

let content : string = fs.readText('./config.txt');
io.println(content);
```
